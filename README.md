# Перевод экрана (EN → RU)

Android-приложение для автоматического перевода текста на экране с английского на русский, Android 10+ (minSdk 29).

## Как работает

1. Вы нажимаете «Запустить перевод экрана» и выдаёте разрешение на запись экрана.
2. Появляется пузырёк поверх экрана — перевод включён автоматически.
3. Каждые N секунд (по умолчанию 2) приложение делает кадр экрана, распознаёт английский текст (ML Kit OCR) и рисует перевод поверх исходного текста.
4. Тап по пузырьку — пауза/продолжение, перетаскивание — перемещение пузырька.
5. Остановить полностью: кнопка в уведомлении или «Остановить» в приложении.

## Режимы перевода

- **Офлайн (ML Kit)** — бесплатно, работает без интернета. При первом запуске скачивается языковая модель (~30 МБ). Качество ниже облачного.
- **Онлайн (Google Cloud Translation)** — лучшее качество, нужен API-ключ:
  1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/).
  2. Включите **Cloud Translation API**.
  3. Создайте **API-ключ** (APIs & Services → Credentials) и вставьте его в поле «API-ключ» в приложении.
  4. Облачный тариф — платный сверх бесплатной квоты (500 000 символов/мес на бесплатном уровне).

Если облако недоступно, приложение автоматически откатывается на офлайн-перевод.

## Сборка

Вариант А — Android Studio: **Open** → выбрать папку проекта → дождаться Sync → **Run** или **Build → Build APK**.

Вариант Б — командная строка (нужен Android SDK):

```bash
gradle wrapper        # сгенерировать gradlew (или откройте проект в Android Studio один раз)
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Структура

| Файл | Назначение |
|---|---|
| `MainActivity.kt` | UI, разрешения (оверлей, уведомления), запуск захвата экрана |
| `TranslationService.kt` | Foreground-сервис: MediaProjection, цикл автообновления, дедупликация неизменённых кадров |
| `TranslatorEngine.kt` | OCR (ML Kit) + перевод офлайн (ML Kit) / онлайн (Google Cloud, OkHttp) |
| `OverlayManager.kt` | Пузырёк-переключатель и оверлей с переведёнными блоками |

## Ограничения

- **Защищённые экраны не захватываются**: банковские приложения, DRM-видео, окна с `FLAG_SECURE` — система отдаёт чёрный кадр. Это ограничение Android, обойти нельзя.
- «Автоматически» = обновление раз в 1–10 сек с проверкой «текст изменился». Непрерывный видеопоток в реальном времени на батарее так не живёт — это осознанный компромисс.
- Захват идёт с фиксированным разрешением на момент старта; при повороте экрана перезапустите перевод.
- Офлайн-модель ML Kit переводит хуже облака, особенно игровой сленг и короткие фразы без контекста.
- Постоянный цикл захвата расходует батарею — используйте паузу (тап по пузырьку), когда перевод не нужен.
